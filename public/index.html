내 자료실

로그인하고 이 기기가 서버에서 승인된 뒤에만 본인의 가상 메모를 조회·추가·수정·삭제할 수 있습니다. 보호 요청은 모두 이 기기의 패스키로 서명해 보냅니다.

오프라인입니다. 보호 자료는 기기에 저장하지 않으므로 연결이 돌아올 때까지 표시하지 않습니다.
이 앱을 홈 화면이나 바탕화면에 설치할 수 있습니다. 설치는 실행을 편하게 할 뿐이며 기기 확인이 아닙니다. 설치한 뒤에도 아래의 기기 승인을 받아야 자료실이 열립니다.

Supabase 로그인

계정으로 로그인됨

기기 승인

서버 승인 상태: 확인 전

보호 요청은 이 기기의 패스키(Windows Hello, Touch ID, 휴대폰 화면 잠금 등)로 서명합니다. 서명은 운영체제 인증기가 만들고, 이 화면은 그 결과만 요청에 붙입니다. 로그인 정보도 브라우저 저장소에 남기지 않으므로 새로고침하면 다시 로그인합니다. 승인은 서버가 최근 10분 안의 실제 로그인과 그 패스키의 서명을 확인한 뒤에만 정하며, 승인 전에는 자료를 받지도 표시하지도 않습니다. 요청할 때마다 인증기 확인 창이 뜹니다.

탈환 작전실

아래 수치는 실제 API 응답(GET /api/ops/summary)에 들어 있던 값만 그대로 보여 줍니다. 먼저 저장된 실측 응답(npm run ops:snapshot)과 같은 시점의 가린 서버 기록 대조 결과를 보여 주고, 버튼을 누르면 지금 응답으로 바꿉니다. 응답이 없으면 "미실행"이며 화면에서 수치를 계산해 채우지 않습니다. 메모 제목·본문은 받지도 표시하지도 않습니다.
